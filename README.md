# ci-jenkins

Jenkins shared library for projects generated by `action-platform`. Logic lives in [ci-scripts](https://github.com/actionplatform/ci-scripts); every step fetches it at `v1`.

Configure once: Manage Jenkins → Global Pipeline Libraries → name `ci-jenkins`, this repo, default version `v1`.

```groovy
@Library('ci-jenkins@v1') _
apPipeline(image: 'python:3.12')
```

| Step | Does |
|------|------|
| `apSetup(language:)` | dependencies |
| `apCheck(language:)` | lint, format, tests |
| `apConventionalCommit(base:)` | Conventional Commits on the change range |
| `apRelease(tag:, files:, branch:)` | version bump from tag |
| `apPipeline(image:, language:)` | declarative pipeline: setup → check → commits (PRs) |

Tag `vX.Y.Z`; `v1` floats to the latest.
